# UberClone — Versión Conductor

App móvil (React Native + Expo) del conductor. Proyecto final de Desarrollo Móvil.

## Instalación
```bash
npm install
cp .env.example .env
npx expo start
```

## Backend
Ver `backend/` (Express). Variables en `backend/.env.example`.
